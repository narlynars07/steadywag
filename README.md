# Steadywag

A public, sourced record of one rare case, and a diet-history tool for other families. Built for the DEV Sanity Challenge, Path One.

- `web/` is the Next.js site: the Ask agent, Today, Check-in, History and Your dog. **Start with [`web/README.md`](web/README.md)** for the architecture and how to run it.
- `studio/` is the Sanity Studio and schema.
- `scripts/` builds and loads the dataset.
- `docs/context-setup.md` is the Sanity Context setup sheet.

Sanity project ID: `yahsq70q` (dataset `production`, public read). Live site: https://steadywag.vercel.app
